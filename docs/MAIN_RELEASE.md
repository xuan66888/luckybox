# 主站版本與即時營運紀錄

本次只部署同一主站 `/` 與獨立管理入口 `/admin/`。舊 `/demo/` GET／HEAD 轉回 `/`，舊模擬付款 POST 回410；不匯入舊體驗會員、點數、VIP、獎池或付款。歷史體驗資料私有保留，不刪除。

## 管理紀錄

後台新增「即時紀錄」：註冊／登入／登出、充值狀態、抽獎物品與成本、點數異動、物品／機率修改及出貨事件。紀錄及總覽K線、曲線每5秒重新向伺服器查詢，不是假推送或毫秒級串流。隱藏分頁、開啟操作對話框時暫停，返回頁面立即更新；亦可手動暫停。

會員及非管理員無權讀取此端點。API不快取，事件摘要以白名單過濾，不能帶出密碼、Token或任意稽核JSON欄位。畫面顯示伺服器更新時間；斷線保留最後紀錄並重試。事件在最近1000筆中篩選，顯示最多50筆；抽獎／充值／點數表各20筆。原始帳本及稽核仍保留，非刪除歷史紀錄。

充值只有production已付款計入正式實收；未付款及stage不算。主機排程及資料來源不改接體驗資料庫。

## 保留的營運決定

異地備份暫緩；保留現有主機每日一致性備份及隔離還原驗證、五分鐘健康檢查。不建立專用金鑰、SSH帳號或本機下載排程。正式收款需另行核准與真人驗收；未推廣不代表公開網站無人存取。
