# 滿池初始機率

商品百分比採用 `prize.quantity / pool.total × 100`，四捨五入至小數點後兩位。原始獎項數量與滿池總抽數保持不變，因此開抽後百分比維持固定。

頁面以「獎品與抽中機率」呈現獎品資料及固定百分比，不顯示每項獎品的動態剩餘／初始份數。圖片與百分比不因商品抽出而消失，也不會另加「已抽完」標籤。整池剩餘抽數、狀態與實際抽獎限制仍由伺服器判斷；固定百分比不是當下庫存的條件機率。

原有承諾值、獎品清單雜湊與抽完後公開的種子，提供抽獎序列核對依據。尚未接入第三方認證服務，不能將本站資料標為第三方認證或商品履約保證。

`tests/initial-odds.e2e.ts` 使用真實資料庫抽至某項剩餘 0 份，驗證初始 25%／75% 保持固定、頁面不出現動態獎品庫存，並檢查 320px 手機版。執行紀錄見 `docs/evidence/normal-validation.log`。
