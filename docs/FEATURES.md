# 交付功能與未實作項目

本版不是把原型每個展示頁掛上雲端儲存。原型的前端全權狀態不可直接變成可信後端，故核心互動改寫為明確 API，原 CSS 保留，原始完整 ZIP 另存 reference。

| 原型功能 | 本版實作 / 說明 |
|---|---|
| 一鍵假登入、官方登入 | Email + scrypt + Session；無預設帳號；管理員以 seed 或既有官方授權建立 |
| 瀏覽器改角色 / 改餘額 | 伺服器授權；角色變動撤銷登入；餘額只能經帳本交易更新 |
| 創作者建立獎池 | 草稿、獎品階層、數量、價格、準備金、送審、審核原因、開池 |
| 官方修改與一般會員修改介紹 | 官方直接改介紹；創作者改自己的內容需覆核；公開頁保留舊稿 |
| 商品圖 / 封面 / 多張介紹图 | 受限圖片上傳，解碼重編碼，資料庫 ownership，持久儲存 |
| 身分 / 庫存 / 官方履約 badge | 申請、官方人工審核後才顯示；不是自動 KYC |
| 抽獎、扣點、庫存 | 同一伺服器交易；有限且不放回的預先承諾序列；重複請求防護 |
| 假 POOL_HASH / COMMIT | 真實種子承諾、獎品清單雜湊；抽完公開種子；隨附離線重建驗證工具 |
| Free Drop / 官方免費池 | 統一到 kind=free 的同一獎池引擎，每帳戶最多一抽；預先保留獎勵點數 |
| 實體獎兌點 | 獎品固定兌點額，由準備金支付；不得重複換點 |
| 個別 / 批次申請出貨 | API 支援最多 50 件同一出貨單位；介面提供逐件申請 |
| 官方出貨 / 創作者出貨 | 官方可處理所有單；創作者只能看及處理自己承擔出貨的單 |
| 玩家收貨 | 真實狀態轉移；出貨後不可兌點 |
| 刪除池 | 官方可取消尚無任何抽獎的池並退還準備金；已有紀錄禁止刪除 |
| 結算 | 售罄、履約、等待期、官方覆核；點數收入、平台費及準備金返還可查；不執行法幣或鏈上匯款 |
| 充值 | 預設停用；可開啟人工付款登記、唯一參考碼與獨立官方覆核 |
| 後台抽獎稽核 | 官方可查玩家與獎品；公開 proof 不含 email / 地址 |
| 玩家錢包 / 抽獎 / 收藏 | 以個別登入帳戶查詢；不共用 Demo User |
| 密碼重設 | SMTP 連結、30 分鐘有效、單次使用、撤銷 session；開發郵件落地檔案 |
| 維運 | production build/start、migration、seed、health、backup、Docker/Caddy 設定 |

以下原型功能**沒有被冒充為完成**；部署入口不顯示其假數字或成功按鈕，原型僅保留供後續開發參考：

- 社群動態、讚數、Club、隊伍、排行榜、每日轉盤、邀請進度、假任務完成。
- Growth Campaign 的社群追蹤/留言驗證、社群登入（Google/Apple/Discord 等）。
- Free Draw 券的跨活動發放與指定官方池券帳本；目前僅實作每帳戶一次的免費池。
- Boost 廣告、熱度演算法的假流量，以及沒有事件追蹤基礎的分析數據。
- Agent / Sub-agent 現金分潤、推薦歸因、現金提領、真實 USDT/信用卡串接。
- 自動物流、地址驗證、退款/拒付、爭議處理、自動 KYC、多因素驗證、真人去重。
- 多主機資料庫、S3/R2 儲存轉接器，以及服務商專屬監控與部署。

這些有些需要第三方憑證，有些需要新的商業規則與額外開發。**它們不是補 `.env` 就能使用的既有功能。** 核心版可以部署並邀請用戶測試；若你的「正式營運」必須包含上述項目，本版仍有待辦，不應視作全平台正式上線驗收。

清單介面目前展示上限：公開及管理獎池/會員 200 筆、收藏 500 件、個人抽獎/帳本 200 筆、出貨 200 筆、結算/個人儲值 100 筆、稽核 300 筆。資料庫不刪除較舊資料；大量營運前應增加可查詢的分頁與搜尋，避免依赖固定清單上限。
