# 隔離模擬體驗站

啟用 `DEMO_ENABLED=true` 後，`/demo/` 提供註冊、模擬付款成功／失敗／取消、虛擬點數、每抽必中、收藏、模擬VIP與任務體驗。

- 專用資料庫：`DATA_DIR/demo/luckybox.sqlite`。不是正式會員、金流、庫存或VIP資料。
- 專用 Cookie：`__Secure-lb_demo_session`（正式HTTPS），限定 `/demo`；不能登入正式站或後台。
- 帳號只接受 `@example.test`，初始0點。請勿使用真實個資或真實密碼。
- 充值為本機模擬收銀台，沒有綠界請款、銀行轉帳、刷卡、真實商品、物流或兌現。
- 3組示範獎池、9個原創示範物品；各池物品機率5%／15%／80%，不是競品圖片或真實供應承諾。
- 充值完成才加點；失敗、取消、跨會員或重複完成不得加點。請求仍有 Origin、CSRF、限流與冪等檢查。
- 示範出貨、供應商與管理端點禁止使用。示範會員上限2000；全站資源仍應搭配邊緣限流與容量監測。
- 主站 Turnstile、正式註冊與金流設定不因模擬站改變。正式收款、付費抽獎與正式贈點未開放。
- 主站備份涵蓋正式資料；示範資料為可重建的非營運資料，不作為財務或履約紀錄。

## 驗收

1. 進入 `/demo/`，建立示範帳號，確認0點。
2. 模擬500點付款失敗，確認仍0點。
3. 模擬1000點付款成功，確認1000點；重複同筆不能再加。
4. 在100點獎池抽一次，確認900點及收藏1件。獎項由伺服器隨機，不保證抽到大獎。
5. 會員中心確認模擬銀卡VIP；領取首抽任務10點後應910點，重複領取不得再加。
6. 登出再登入確認點數與收藏保留；正式站不應出現這個帳號或獎池。

## 仍需營運方完成

Google OAuth與帳號2SV、SMTP寄信與網域驗證、簡訊供應商、綠界商業模式核准與正式金鑰、管理員MFA、真實庫存／出貨／客服／政策、實機驗收、異地備份與外部告警接收者。這些不能用模擬成功代替正式驗收；部分退款自動化與付費／贈點來源逐筆歸屬尚未宣稱完成。
