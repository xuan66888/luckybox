# 正式站互動與人工調點

- 選籤為呈現層，不改變公告抽獎模式。原有POST抽獎合約、付費開關、機率版本、冪等、庫存交易保持不變。
- 手機Pointer Events／桌面滑鼠拖曳紙角；鍵盤滑桿、直接揭曉、全部揭曉、可關音效。減少動態偏好不播放首頁裝飾動畫。
- 網路中斷保留原交易key（sessionStorage，不含密碼），重新整理只讀原結果；明確重試仍使用原key，不自動扣點。
- GET /api/me/draws/:id 及 /api/me/draw-requests/:key 僅本人可讀，不執行抽獎。
- 首頁預告僅公開原本獲准的3個商品名稱與原創概念示意圖，不公開任意草稿、供應成本、來源、私有描述或假庫存／價格。可抽仍為0。
- ADMIN_BALANCE_ADJUSTMENTS_ENABLED預設false。啟用後僅管理員可為啟用中的一般會員／創作者加扣整數點數；不准自己或其他管理員。每筆1–100000點，餘額0–1000000000。
- 必填5–500字原因，另可填工單碼。預覽前後餘額、再次驗證目前密碼；已啟用MFA則必須再次驗證，失敗5次暫停15分鐘。
- 原子交易寫入餘額、append-only ledger、balance_adjustments及audit；預期餘額比對避免覆蓋其他交易。冪等指紋不含密碼／OTP。
- 人工調點不是綠界儲值／銀行扣款／退款，絕不創建paid訂單、不算付費VIP、營收或邀請實收資格。即時紀錄沿用5秒更新。
- 所有正向操作測試使用本機一次性fixture；不得為正式用戶代做真實加扣點／抽獎。
- 原先延後的Google OAuth、SMTP、SMS、正式金流、真實現貨、異地備份仍未啟用；不可聲稱已完成外部商業驗收。

- 同一主頁提供「試撕紙籤（不抽獎）」純前端預覽：不呼叫抽獎／調點API，不產生結果、收藏或紀錄；沒有另開demo路由。
