# LUCKYBOX 管理後台與獨立機率（2026-10-27）

管理後台為獨立網址 /admin/，使用專用管理員登入頁及 /admin.js 入口；用戶網站 / 不顯示後台導覽或管理按鈕。
首次管理員仍由既有 seed 建立，沒有新增預設帳密。專用登入 API /api/auth/admin-login 只接受有效管理員。
一般用戶即使輸入 /admin/ 也只能看到無權限提示，不能取得後台資料。網址區隔不是唯一防護，伺服器 role / CSRF 檢查仍保留。
目前仍是同一網站的獨立路徑，不需要額外購買網域；未來可再用反向代理配置 admin 子網域。

## 管理功能

- 營運總覽：24小時／7天／30天；會員、獎池、正式綠界實收、今日抽獎、出貨待辦。
- K線圖：會員可用點數總量的開／高／低／收，以不可變帳本計算；不是股票／商品價格。
- 曲線圖：所選期間的累計抽獎次數。無資料不補假行情；空桶延續實際點數存量。
- 註冊用戶：名稱／Email搜尋、角色篩選、分頁、新增、編輯資料、角色修改與停用；公開註冊沿用原流程。
- 管理帳號：獨立列出管理員，新增管理員；不能修改自己的管理權限，角色／Email變更撤銷相關登入。
- 物品：依獎池管理名稱、類型、商品圖、庫存、參考價值與兌點額；庫存／規格僅限未送審的草稿或退回修改。
- 機率：每個物品可獨立填0～100%，精度0.01%，合計必須100%；可調整未結束獎池，包括已核准與開放中的池。
- 既有獎池審核、出貨、人工儲值與點數結算功能保留於營運總覽待辦及「審核與出貨」。

## 個別機率模式

例如大獎1%、二獎9%、三獎90%，與各自庫存數量無關。點「調整機率」並儲存後，該池切換為 weighted。
每一抽由伺服器使用 crypto.randomInt 依當下可用權重取樣，抽中才扣一件庫存。0%物品不會被抽中。
售罄物品自動排除，其他物品按原權重比例重新換算；前台顯示目前有效機率。
若所有剩餘庫存的權重都是0，抽獎暫停，不扣點；由管理員重新調整。
例如大獎1%、二獎9%、三獎90%，三獎售罄後，有效機率為大獎10%、二獎90%。

修改即時生效並產生 odds_version 與 audit 紀錄。玩家頁面版本過舊時會要求重新開啟獎池，不以過期顯示直接扣點。
這是設定更新檢查，不是原有承諾驗證。

weighted 模式不使用原本預先承諾的 ticket 順序，也不生成新的承諾序列；前台移除該池的舊驗證入口。
proof API明確回傳 verifiable=false，而不是偽稱仍可驗證。未設定獨立機率的舊池維持舊引擎，以免默默改動其抽獎行為。
已售罄／取消／結算的池不能再改機率。開放中的池可改機率，但不能直接改獎品規格、歷史庫存或已發出的收藏。

## 安全與資料

管理API必須經伺服器admin權限、Origin、CSRF、Idempotency-Key檢查。密碼使用原有scrypt，不出現在列表或audit。
機率更新與抽獎都在 BEGIN IMMEDIATE 交易中執行，避免半套設定、重複扣點、超賣；同一管理設定重送不重複套用。
獎品清單必須完整、無重複且屬於該池；百分比由整數basis points儲存，不接受前端覆寫抽獎結果。
綠界stage測試交易不算正式收入，人工核款也不會被誤算成綠界自動實收。
綠界正式收款仍保持關閉；本次未部署主機、未使用正式金鑰、未推送GitHub。

## 驗證與回滾

新增 tests/admin.test.ts 與 tests/admin.e2e.ts；覆蓋管理權限、帳號、搜尋、物品、個別機率、實際抽中結果、圖表與手機版。
預覽圖使用隔離測試帳戶和測試資料，並非正式營運數據。
同一交易的 DIFF_FILE.patch 可由最初來源重建本次整個副本（含既有綠界串接）。
ROLLBACK.sh 接受標記的測試源碼副本：預設還原到後台改造前的綠界版本；第二參數 initial 才還原至最初來源。
回滾只驗證源碼副本，不會修改正式資料、.env或金鑰。SQL是前進式migration；正式資料庫降版必須停機並用備份獨立驗證，不能直接套用源碼回滾當成資料回滾。

## 每池物品與未中獎
機率依獎池 ID 與該池物品 ID 設定，並非全局；每池可有 1–100 個自訂名稱的物品／結果。機率編輯器顯示獎池名稱、ID、圖片、類型並支援池內搜尋；搜尋隱藏的項目仍會一併儲存。未中獎使用 none 類型、價值與兌點額均為 0，不產生收藏、點數獎勵或出貨。空籤份數同樣有限，用完即排除並重新換算其他有效機率。新增物品／未中獎須在草稿或退回階段完成，送審後不可改規格／庫存；已上架池只能調整各項機率。每池所有結果（含未中獎）合計為 100%，儲存不影響其他池。
