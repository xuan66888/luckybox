# LuckyBox 工作日誌

記錄功能、測試範圍與未完成事項；不公開帳密、金鑰、用戶／收件資料或原始執行日誌。時間以 UTC+8 為準。

## 2026-10-28｜同步現行部署原始碼

### 已完成的程式與介面

- 用戶站與 `/admin/` 管理中心分離；基本 Email／密碼註冊及登入，登入後保留原目的頁，帳號資料異動會撤銷舊登入。
- 管理員帳號／會員管理；人工加點、扣點必填原因、重新驗證管理員、檢查餘額與版本，並保留帳本及稽核紀錄；人工加點不代表收款。
- 每個獎池／物品獨立設定機率；成功抽取必有獎項，不使用未中獎項；有限庫存、同時抽取與重試避免重複扣點。
- 主站選籤、手動撕籤及結果回看；適配手機、平板、電腦，支援減少動態效果。
- 三款實體商品參考照片與來源註記；照片不是本店實拍，也不證明有現貨。來源見 `PRODUCT_PHOTO_SOURCES.json`。
- 主站免費功能測試池：不扣點、不發實體、不兌點、不出貨；資料與正式抽獎、收藏、營收及活動獎勵分離。
- 後台測試池每 5 秒更新；可暫停更新、調整每件機率及經確認下架／恢復。下架只隱藏入口，不刪歷史、不重設結果；修正超過最近 200 筆後的舊結果回看。
- VIP、任務、邀請獎勵與預算可配置；LIVE、K 線／曲線及即時紀錄使用資料庫資料，不生成假流量或假得獎。
- 點數來源、退款保留額與對帳；商家／政策草稿、公開版本及同意紀錄；主機健康檢查、備份與隔離還原檢查。
- 已準備 Google、寄信、簡訊、Turnstile 與綠界的串接程式；程式具備不等於外部服務已核准或正式驗收。

- Git 發布副本統一文字換行為 LF、移除一處空白行的尾端空格，加入 `.gitattributes`；不改動原部署來源，應用程式內容以換行／空白行正規化後核對；商品照片容器保留原始位元組與來源雜湊。

### 已執行的驗證

- 現行應用程式 `npm run check`：lint、TypeScript、145 項測試及 build 通過；GitHub 發布副本會再執行相同檢查。
- `npm run smoke`：正式模式啟動、安全 Cookie、持久化、重新啟動、備份與不應公開路徑檢查通過。
- 隔離本機全流程：註冊、僅本機郵件驗證、邀請綁定、合成簽章付款通知、VIP、抽獎與重試回復、收藏、虛構出貨／收貨、人工加扣點、模擬退款及重新登入／對帳；未呼叫真實付款或寄送服務。
- 原生容器基線／新版／回滾比對及原始位元組還原通過；正式站資產雜湊與部署來源核對一致。
- 瀏覽器已操作主站選籤／撕籤與後台即時更新、下架／恢復、暫停／恢復；完成多種 CSS 視窗尺寸檢查，並未宣稱實體 iOS／Android 已驗收。
- `npm audit --omit=dev` 當次回報 0 個已知漏洞；不是完整滲透測試或未來安全保證。
