# 認證狀態撤銷與競態保護

- 一般／管理員密碼登入在非同步 scrypt 完成後，於同一個 SQLite 寫交易重新核對帳號啟用狀態、Email、角色與密碼雜湊。任一變更都不建立 Session；一般資料或餘額更新則回傳最新資料。
- MFA 檢查、復原碼消耗、登入稽核與新 Session 一起提交。不能沿用驗密前的一般會員角色來跳過剛生效的管理員 MFA。
- MFA 設定、啟用、停用同樣核對有效管理員 Session；再次驗密期間登出、改密碼、停權或撤銷角色後，請求不得再寫入設定。
- 後台變更會員 Email 會撤銷該會員 Session、Email 驗證、密碼重設與未完成 Google 綁定 state。只改暱稱不撤銷有效重設連結。
- 後台修改角色／停用狀態會撤銷 Session、重設連結和未完成 Google 綁定。舊資料中的停用帳號重設 token 也被拒絕。
- 此次不改密碼政策、不啟用任何供應商、不修改正式帳號憑證／角色／MFA；回歸測試只操作隔離帳號。

驗收：`npm run check`、`npm run smoke`；`tests/auth-revocation.test.ts` 以真實本機 HTTP 與受控的非同步交錯重現撤銷，並驗證正常登入、MFA、正常新信箱重設仍可用。這不代替外部 Google／SMTP／簡訊與真人驗證器驗收。
